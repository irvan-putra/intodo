# tindak 0.5.19 test release

Visible app and widget labels use tindak. The existing package, signer, saved preferences, pairing key, feed settings, task data, update endpoints and compatibility asset filename remain unchanged. No automatic phone update or account change.

The browser-local task page is separate from Android. It has no phone sync or timed alerts. Keep backups private; task backups contain unencrypted text and clearing browser data can erase tasks.

The signed Android release remains a test build. Synthetic browser checks do not prove behavior on a physical phone. DeltaChat accounts, mini-app instances and runtime message behavior are not migrated or activated by the rename.
