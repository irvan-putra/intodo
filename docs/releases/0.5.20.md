# tindak0.5.20 identity-reset test

The repository, Android package and task website are now actually tindak, with a new check-arrow icon. Android package com.vanipy.tindak, version code35. Separate install from previous com.vanipy.intodo versions, not an in-place update. Previous tagged releases remain available unchanged. Current updater and miniapp downloads use the Tindak repository and names.

Old configuration and browser state are not migrated, as requested. Create a new on-device pairing key and send only its public key for reminder-feed setup. Existing reminder content and encrypted feed are not deleted or re-paired by this release. Bot account login/setup is not copied, created, sent or altered automatically. Widgets must be added for the new install. Keep the old app until setup is complete if you still need it.

Browser tasks are local and separate from Android, with no task sync or timed alerts. Both the original review prototype and separate code-review canvas remain. All current features are retained in source. This test is not physical-phone upgrade, pairing, bot continuity or alarm proof. No new permissions beyond the existing seven are added. The existing signing key is retained, but package change still requires a separate install.
