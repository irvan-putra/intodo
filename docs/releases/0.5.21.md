# tindak0.5.21 test build

The demo now comes with the app. It contains six fictional reminders/tasks, works offline without a pairing key or feed address, and stays separate from real reminders in the app and widgets.

Real-feed setup now asks only for your real feed URL. No demo feed URL is required. Your existing pairing key, real address and cached real reminders are kept. Any earlier external-demo cache/address is retained locally in recovery preferences while the bundled demo takes over. Replacing a pairing key explicitly still clears the real cache as before, but no longer removes the built-in demo.

Demo does not sync to a server or schedule alarms. Returning to the real list still requires confirmation because real reminders become visible. Real sync still requires the phone's existing matching key and a usable real feed URL; saving the URL alone does not prove sync worked.

Update over tindak0.5.20, not the old Intodo package. Same com.vanipy.tindak identity and signing key. No new Android permissions. No feed URL, personal reminders or private key is bundled. Public APK has the new0.5.21version badge on adaptive and legacy launcher icons.

Native synthetic preservation, setup and render tests are collected separately. Physical-phone install/demo/real-sync acceptance remains pending user retest. Browser code-review page remains separate; its loading/retry safeguard is already live.
