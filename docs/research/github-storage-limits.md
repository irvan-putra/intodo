# Supplement: GitHub as storage has limits

Read from GitHub's own pages on 2026-11-16.
- GitHub blocks ordinary Git repository files larger than 100 MiB. Repositories should stay small: ideally under 1 GB, and under 5 GB is strongly recommended. A repository that excessively impacts GitHub's infrastructure can be asked to take corrective action. https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github
- The Acceptable Use Policies have a section on excessive bandwidth use: usage far above other users of similar features can lead to throttled file hosting or a limited account. https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies

So encrypted GitHub storage can be considered for small files within GitHub's applicable policies; large or heavily downloaded data should use a service designed for that purpose.
