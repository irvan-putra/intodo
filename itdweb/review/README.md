# Review canvas (static, GitHub Pages)

A standalone static build of the section-by-section review canvas for
irvan-putra/intodo, pinned to commit 7e0bb57 (see `../src/sections.ts`,
generated by `../tools/gen_sections.py`).

Full-screen, FreeForm/Miro-style: the canvas fills the whole window - no
page framing, no square viewport, and no navigation controls or minimap.
Drag the background or a fixed card to pan; pinch to zoom. At the far zoomed-out
context level, tap a group to open its sections. At closer levels, tap a card's
Focus to read it (on phones that opens a full-screen readable overlay; on larger
screens the camera focuses the card).

Unlike the hosted canvas in `../src/App.tsx`, this variant:

- has no platform dependency: `files-shim.tsx` replaces `@instinct/files`
  with a tiny localStorage-backed `useLocalState`, so the review UI runs
  as a plain static page;
- pans infinitely: camera x/y are unclamped (zoom still clamped);
- keeps review marks and camera position in the visitor's browser only
  (localStorage key prefix `intodo-review.`); cards cannot be rearranged.
  A notice appears only if saving fails. Nothing is sent anywhere; marks from
  the hosted canvas do not carry over (different origin and storage);
- shows public repo content only: section text and public file links.

## Build and deploy

    sh itdweb/review/build.sh            # writes itdweb/review/dist/
    # on the gh-pages branch:
    mkdir -p review && cp /path/to/dist/* review/
    git add review && git commit -m "itdweb: static review canvas" && git push

The page then lives at https://vanipy.com/intodo/review/ alongside the
existing demo at /intodo/.
